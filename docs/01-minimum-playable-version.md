# Version 1：Minimum Playable Tetris

Version 1 的目標是建立一個最小可玩的 Tetris。這個版本刻意保持簡潔，方便教學時理解 Swing 視窗、遊戲狀態、碰撞偵測與鍵盤事件。

## 已完成功能

- 使用 Java Swing 建立視窗與遊戲面板。
- 使用 `javax.swing.Timer` 讓遊戲每隔一段時間更新一次。
- 棋盤大小為 10 x 20。
- 方塊會自動往下掉。
- 鍵盤可以控制目前方塊：
  - Left：向左
  - Right：向右
  - Down：向下
  - Up：旋轉
- 方塊不能超出棋盤邊界。
- 方塊不能穿過已固定的方塊。
- 方塊無法繼續下落時會固定到棋盤。
- 固定後會產生下一個方塊。
- 新方塊一出現就碰撞時，遊戲顯示 `Game Over`。
