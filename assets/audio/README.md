# Audio Assets

This teaching repo does not include `katusha.mid`.

The reason is that music may involve composition, arrangement, recording, and distribution rights. To keep this repository simple and legally clean, audio files are intentionally left out.

To enable background music in the future, place a legally obtained or self-created MIDI file here:

```text
assets/audio/katusha.mid
```

If this file does not exist, the game still runs normally. It will show a warning in the console and the UI will show music as unavailable.

Optional sound effect files for future use:

```text
assets/audio/clear.wav
assets/audio/drop.wav
```

If these optional files do not exist, the game still runs normally.
